# 网站使用说明（学生 / 家长 / 管理员）

## 一、查看学生详情

1. 打开网站，进入「学生」页面，点击目标学生
2. 在密码门中输入**访问代码**后进入：
   - 学生本人：输入自己的访问代码（默认为**姓名全拼**，如 `wangxiaoming`）
   - 管理员：输入管理员代码（默认 `admin`），可查看所有学生
3. 进入后右下角有身份悬浮按钮，点击可切换其他身份

> 同一设备只需输入一次代码，浏览器会记住身份；换设备需重新输入。

## 二、知识点自助标记

进入学生详情页的「知识点」栏目：

- **点击白色（未掌握）知识点** → 变绿，标记为已掌握（记录认证月份）
- **点击绿色（已掌握）知识点** → 取消掌握
- 知识点按难度分级显示，绿色数量即当前掌握进度

## 三、管理员：新增学生

在项目根目录执行（服务器或本地）：

```bash
node scripts/add-student.js --name 王小明 [--bio 简介] [--atcoder 账号]
```

脚本会**自动生成访问代码（姓名全拼）并写入数据库**，无需手工配置。
比赛成绩、任务等数据继续使用更新脚本或由 Kimi Work 协助录入。

## 四、常见问题

| 问题 | 解决 |
|---|---|
| 忘记访问代码 | 联系管理员查询数据库 `students.accessCode` 字段 |
| 提示"代码不正确" | 检查拼写；全拼不含空格和声调 |
| 想清空已记住的身份 | 点击右下角身份按钮 → 切换访问身份 |

## 五、安全说明

- 访问代码用于区分学生与管理员，属基础访问控制，**请勿在公开渠道传播管理员代码**
- 更严格的安全方案（如密码哈希、登录会话）后续升级
